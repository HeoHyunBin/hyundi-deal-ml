# hyundi-deal-ml
# 현대자동차 중고차 시세 예측 및 저평가 가성비 매물 탐지

## 실행 방법 (Google Colab 기준)
1. 본 저장소의 `hyundi_deal_detection.ipynb` 파일을 Google Colab에서 엽니다.
2. 상단 메뉴의 **[런타임] → [모두 실행]**을 클릭합니다.
3. 첫 번째 셀에서 자동으로 본 GitHub 저장소를 클론하여 `./data/hyundi.csv` 데이터를 불러온 뒤, 전처리·모델 비교·하이퍼파라미터 튜닝·가성비 매물 탐지 시각화까지 일괄 실행합니다. (별도 구글 드라이브 마운트 불필요)
